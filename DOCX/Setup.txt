# Hướng dẫn cài đặt và chạy project

## 1. Yêu cầu hệ thống

* Python >= 3.10
* pip (Python package manager)
* Git (khuyến nghị)

---

## 2. Clone project

```bash
git clone <link-repo>
cd OS_Group08_OS_SCH_04
```

---

## 3. Tạo môi trường ảo (virtual environment)

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / MacOS

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 4. Cài đặt thư viện

Nếu có file requirements.txt:

```bash
pip install -r requirements.txt
```

Nếu chưa có:

```bash
pip install pytest
```

---

## 5. Chạy chương trình

```bash
python main.py
```

---

## 6. Chạy test (pytest)

```bash
pytest
```

---

## 7. Lưu ý

* Nếu bị lỗi thiếu thư viện → cài bằng:

```bash
pip install <ten-thu-vien>
```

* Nếu dùng PyCharm → chọn đúng interpreter là venv
